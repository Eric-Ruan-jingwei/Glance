# 快捷键

默认全局快捷键可在设置里改。Glance 不申请辅助功能（Accessibility）权限。

| 动作 | 默认快捷键 |
| --- | --- |
| 快速记录 | ⌥⌘J |
| 全局搜索 | ⌥⌘K |
| 剪贴板 | ⌥⌘V |
| 文件架 | ⌥⌘F |
| 片段库 | ⌥⌘S |
| 链接库 | ⌥⌘L |
| 从当前剪贴板创建 | ⌥⌘B |
| 隐藏 / 显示 | ⌥⌘G |

组合必须至少包含 Command、Option、Control 中的两个。Glance 不会把同一组合分给两个命令。

在设置里点一项，按下新组合即生效。Escape 取消。恢复默认会回到 `⌥⌘J` / `⌥⌘B` / `⌥⌘G` 等出厂组合。

状态菜单显示当前已注册的快捷键；未生效的冲突会在设置里提示。

菜单栏没有 Dock 图标，也没有传统主窗口。菜单结构大致为：快速记录、搜索 Glance、剪贴板 / 文件架 / 片段库 / 链接库、面板（新建、从剪贴板创建、管理面板、工作区、隐藏全部）、使用指南、设置、退出。数据恢复项只在备份恢复、损坏元数据或不受支持的 schema 之后出现。
