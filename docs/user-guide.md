# Glance 使用说明

这是产品行为说明，不是 GitHub 首页。实现边界见 [架构](architecture/core-platform-boundary.md)，磁盘格式见 [数据格式](architecture/data-format.md)。

Glance 是菜单栏应用（`LSUIElement`）：看菜单栏里的图钉图标，不要在 Dock 里找。

六个工具平级：面板、剪贴板、文件架、片段库、链接库、全局搜索。Quick Capture 把内容送进这些工具，并不额外发明第七个顶层工具。

## 核心循环

记录 → 放进对应工具 → 需要时用全局搜索找回 → 复制、打开、或做成面板。源记录在派生出面板时不会被删掉或改写。

## 面板

支持文字、Markdown、待办、图片、PDF。

- **Markdown**：渲染预览，点击编辑 UTF-8 `content.md`。
- **待办**：可添加、行内编辑、完成、删除。载荷是 UTF-8 `todo.json`。没有排序、截止日期、提醒或优先级。
- **PDF**：导入时复制进 Glance 数据目录。删除原文件不会让面板变空。密码保护的 PDF 会被拒绝。阅读用 PDFKit：连续纵向滚动、自动缩放、可选中和复制。阅读位置不保存。
- **自定义标题**：只改显示名，不改底层内容。清空后回到由内容生成的自动标题。写入最长 80 字。
- **标签**：多值、轻量，用于搜索和筛选。标签不是工作区，不会改变可见性。单标签最长 24 字，每面板最多 12 个。
- **钉住 / 锁定 / 点击穿透 / 透明度**：按面板保存，重启后恢复。透明度 30%–100%。
- **锁定**：阻止误拖、缩放和内容编辑；PDF 阅读（滚动、选择、复制）仍可用。右键、解锁、透明度、钉住、点击穿透、隐藏、重命名、标签、删除、面板设置仍可用。
- **点击穿透**：忽略鼠标，直到按住 Option。锁定优先：Option 可以打开菜单和设置，但不能移动、缩放或编辑已锁定面板。
- **贴边吸附**：拖到屏幕边缘松手即吸附，尺寸不变。靠近两角时吸到角落。松手时按住 Control 可跳过本次吸附。
- **布局预设**：右键 → 布局 → 左上 / 右上 / 左下 / 右下 / 居中。使用当前显示器可见区域（避开 Dock 和菜单栏）。锁定面板不能移动，布局菜单不可用。

隐藏面板不会删除它，状态会随重启保留。全局隐藏 / 显示是临时的，不会覆盖单面板隐藏。显示全部只恢复「当前工作区且未被单独隐藏」的面板。

右键还可：重命名、编辑标签、移动到工作区、隐藏此面板。把面板移出当前工作区会立刻从桌面消失，但 `isHidden` 标志不变。锁定面板仍可改名或打标签。

## 工作区

每个面板只属于一个工作区。切换工作区只改变桌面上能看到哪一组，不改位置、内容或单面板隐藏。

- **默认** 始终存在，不能改名或删除，id 固定为 `default`。
- 可从状态菜单或面板管理侧栏新建。重名会被拒绝。
- 删除用户工作区时，其中的面板进入「默认」，面板本身不删除。
- 当前工作区记在设备偏好里，不写入 `panels.json`。
- 新建面板（含 Quick Capture / 从剪贴板创建）进入当前工作区。
- 真正可见需要：同一工作区 **且** 未被单独隐藏 **且** 未被全局隐藏。切换工作区不会取消全局隐藏。

空工作区是合法的：桌面没有 Glance 面板，管理窗口会说明这个工作区还没有面板。

## 面板管理

「管理面板…」打开普通 macOS 窗口，不是浮窗，也不写入 `panels.json`。左侧切换工作区。可按类型或标签筛选，搜索标题和标签，隐藏 / 显示、重命名、改标签、移动工作区、把可见面板带到前面，或按面板菜单同样的确认删除。

可多选筛选结果，批量隐藏 / 显示、移动工作区、增删标签。全局隐藏期间管理窗口仍可见；在管理窗口里显示某面板只会清掉该面板的隐藏标志，窗口要等「显示全部」才会出现。

## Quick Capture

默认 `⌥⌘J`。出现在指针所在显示器上。它不是面板：不写入 `panels.json`，没有载荷目录，关闭即丢弃草稿。

- 空草稿打开时可以预填当前剪贴板（文字、http(s) URL 或文件 URL），但不会立刻保存。
- 分类为 **文字**、**链接**（仅 `http`/`https`）或 **文件**。`example.com` 仍算文字。
- 默认动作：文字 → 存为片段；链接 → 存到链接库；文件 → 加入文件架。文字还可以创建文字面板或待办面板。单张图片或单个 PDF 可以创建面板。多个文件只能进文件架。动作不会自动执行。
- `↑` / `↓` 切换动作。`Enter` 或 `⌘Enter` 执行。输入文字时 `Shift+Enter` 换行；选择「创建待办面板」时待办仍是单行，`Shift+Enter` 会提交。
- 空输入不保存。保存失败会留下草稿并给出短错误。
- 送到文件架时只给原文件做书签，不移动、不删除。
- Escape 或点到窗口外关闭并丢弃草稿。
- 即使 Glance 处于全局隐藏，Capture 仍会显示。提交出的面板 `isHidden = false`，但要等显示全部之后才出现在桌面。

## 从当前剪贴板创建

默认 `⌥⌘B`（不是 `⌥⌘V`，以免挡住 Finder 的「将项目移到此处」）。只在你触发命令时读剪贴板，不会为此打开剪贴板历史。

有效图片优先于文字；图片读不出但文字可用时回退到文字。空或不支持的内容不创建面板。全局隐藏时新面板会被创建但保持隐藏。

## 剪贴板

打开本地记录后，Glance 保存最近的文字和图片，可以收藏，并把选中项写回系统剪贴板。它不会自动粘贴。剪贴板历史不是片段库。

## 文件架

拖入文件，或用 `+` 添加。Glance 存引用和 macOS bookmark，不复制文件。可搜索最近和收藏、打开、在 Finder 中显示、Quick Look、复制或再拖出去。从文件架移除不会删除原文件。图片 / PDF 可以从文件架做成面板；做成面板时面板会保存自己的一份拷贝，文件架条目仍是书签。

## 片段库

有意保存的长期文本：地址、回复、提示词、命令。可编辑，不会自动删除。Enter 把原文写入系统剪贴板，由你自己粘贴。从剪贴板保存片段时，写入系统剪贴板不会再生成一条剪贴板历史。

## 链接库

有意保存的 HTTP/HTTPS 页面：仓库、文档、仪表盘。Enter 用默认浏览器打开。Glance 不抓标题、favicon 或页面预览。

## 全局搜索

默认 `⌥⌘K`。在内存里检索 Glance 自己的数据：剪贴板、文件架、片段、链接，以及所有工作区的面板。不写搜索索引，不搜设置、指南、磁盘其余部分、浏览器或网络。

- 空查询显示最近使用的 20 条，按活动时间排序。钉住 / 收藏不加权。
- 非空查询做不区分大小写、不区分变音符号的子串匹配，按标题精确 / 前缀 / 子串再按次要字段排序，最多 50 条。
- Enter：还原剪贴板、打开文件架文件、复制片段、打开链接、或显示面板（必要时切换工作区）。不会打开对应工具的管理窗口。
- `⌘Enter` 在来源库中显示该条。
- 缺失文件、无效链接、全局隐藏会留在搜索窗口并给出提示。显示面板不会悄悄关掉全局隐藏。
- 面板摘要在后台加载。改查询只过滤内存结果。

## 隐私

Glance 留在这台 Mac 上。不需要账户，不上传搜索内容，不自动抓取网页。全局搜索不扫描任意用户文件，不搜索文件架文件内容，不对剪贴板图片做 OCR。

## 设置

包含登录时启动（`SMAppService.mainApp`）、可自定义的全局快捷键、剪贴板历史开关、本地数据目录，以及来自 app bundle 的版本号。

## 数据位置

默认：

```text
~/Library/Application Support/Glance/
```

测试和演示可以用环境变量 `GLANCE_DATA_ROOT` 改根目录，不会改生产数据。没有保存按钮；移动、缩放和文字编辑会防抖，退出时刷盘。

完整字段与 schema 见 [数据格式](architecture/data-format.md)。
